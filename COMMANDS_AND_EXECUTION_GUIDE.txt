================================================================================

   python app.py

Step 4: Open the URL on your mobile phone (Chrome / Safari / Firefox):
   - Sign in with your account credentials.
   - Your Gemini API Key from your account database profile will be loaded automatically.
   - All fetch requests include automatic `ngrok-skip-browser-warning` bypass headers.

4. DATABASE INSPECTION COMMANDS (CHECK USERS & ACTIVITY)
================================================================================

--------------------------------------------------------------------------------
OPTION A: Built-in Python Database Inspector (Fastest & Easiest)
--------------------------------------------------------------------------------
Run this single command from your project folder:
   python check_users.py

What it prints:
   - Full list of registered users (ID, Name, Email, Registration Date)
   - Active users and total conversations per user
   - Last active timestamps

--------------------------------------------------------------------------------
OPTION B: SQL*Plus / Oracle SQL Developer Queries (Oracle XE)
--------------------------------------------------------------------------------
Login to Oracle Database XE:
   sqlplus yadam/gopi@localhost:1521/XE

1. View all registered users:
   SELECT user_id, name, email, created_date, preferred_lang, theme FROM users ORDER BY user_id ASC;

2. Check user passwords & API key status:
   SELECT user_id, name, email, password, api_key FROM users;

3. Check active user conversations:
   SELECT user_email, COUNT(conversation_id) AS total_chats, MAX(updated_at) AS last_active
   FROM conversations
   GROUP BY user_email
   ORDER BY last_active DESC;

4. View recent messages sent by users:
   SELECT c.user_email, m.sender, SUBSTR(m.content, 1, 60) AS preview, m.created_at
   FROM messages m
   JOIN conversations c ON m.conversation_id = c.conversation_id
   ORDER BY m.created_at DESC;

5. Check active password reset tokens:
   SELECT token, user_email, created_at, expires_at, used FROM password_resets ORDER BY created_at DESC;

--------------------------------------------------------------------------------
OPTION C: SQLite Direct Queries (If using SQLite fallback)
--------------------------------------------------------------------------------
Inspect SQLite tables with Python one-liner:
   python -c "import sqlite3; c=sqlite3.connect('database/chatbot.db').cursor(); print('USERS:'); [print(r) for r in c.execute('SELECT user_id, name, email, created_date FROM users').fetchall()]"

10. TROUBLESHOOTING & COMMON ISSUES
================================================================================

Problem 1: "Gemini API quota / rate limit reached (429)"
   Cause: Google AI Studio Free Tier allows 15 requests per minute (RPM).
   Solutions:
   1. ⏳ Wait 30–60 seconds for the RPM window to reset.
   2. ⚡ In the top header of the chat screen, switch model to "💨 Gemini 3.5 Lite" (supports 30 RPM).
   3. 🔑 Open Settings (⚙️), paste a fresh Gemini API Key from https://aistudio.google.com/app/apikey, and save.
   * Note: The backend automatically cascades across fallback models (gemini-2.5-flash -> gemini-3.5-flash-lite -> gemini-3.7-flash -> gemini-2.5-pro).

Problem 2: "Mobile shows API error or warning screen on ngrok"
   Solution:
   - Ensure you are logged into your account on mobile. Your API key will sync from the database.
   - All API fetch calls automatically include `ngrok-skip-browser-warning: 'true'`.

Problem 3: "Oracle Database connection failed"
   Cause: Oracle service is not started or Instant Client path is missing.
   Solution:
   - The application automatically falls back to SQLite (`database/chatbot.db`) so the app never crashes.
   - To use Oracle, ensure OracleServiceXE is running in Windows Services (`services.msc`).
